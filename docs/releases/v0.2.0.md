# v0.2.0 · 2026-11-08

此版本新增内置后端、统一 Windows 安装和视频预览，按兼容功能新增升级 MINOR。版本来源为 `cep-extension/CSXS/manifest.xml`，bundle 与 panel 均为 0.2.0；CEP schema 仍为 7.0。本说明与该版本源码共同维护，验证范围及限制见下文。

## 新功能

- 仓库及 setup 包含固定来源的 Python backend、四类模板、来源与许可记录；面板 ZIP/ZXP 仍需另行配置后端环境。
- 内容区域校准、评分缓存、自动结果与人工覆盖分离、撤销/恢复自动、版本化 NPZ 与 JSON 提交、跨进程锁及冲突检测。
- Windows 在线 setup 安装独立 CPython 3.13.2、NumPy 2.2.3、opencv-python-headless 4.11.0.86。健康组件复用，面板和后端按内容更新，失败回滚。
- 常驻源帧预览、内容区域叠框和剪后跳切试听；可选 FFmpeg 支持解码与不兼容编码的 H.264/AAC 播放代理。

## 修复

- 安装空路径、特殊字符路径、损坏配置处理、安装锁释放与 CEP 扫描目录内备份问题。
- 从锁定 SHA256 的原始归档重建组件清单，拒绝以可修改的本地清单或一次 import 成功代替完整性验证。
- 预览元数据缺失导致下一帧停在0、无图时破图、代理租约释放与配置保存失败状态。
- Premiere 保存返回 true 被误报为失败；当前严格接受 true 或 0，其他返回仍报失败。
- manifest 结构及面板 ID 校验、发布包内容逐字节校验。

## 性能证据及边界

完整原片1920×1200、60fps、实际解码95955帧：历史 OpenCV/32 workers 约786秒，新 FFmpeg/4 workers 加内容区域校准为124.50秒，约6.3倍。两轮同时改变内容区域与评分缓存，不能归因于单项优化或承诺通用倍数。

受控1800帧短片每组3次，OpenCV/4 workers 中位14.488秒，FFmpeg/4 workers 为3.288秒；该短片 states 与 keep_ranges 相同。峰值私有提交分别4132MiB与4141MiB，不等于驻留物理内存。核心测量与已知限制见[验证状态与已知限制](../verification-status.md)，没有新全片峰值内存验收。

四个诊断源帧吻合不是独立准确率测试；不宣称98%分类准确率或99%暂停召回率。

## 安装与升级

1. 下载 `arknight-pr-setup-v0.2.0-windows-x64.zip`，完整解压到新目录，关闭 Premiere，双击 `setup.bat`。
2. 缓存每次使用均核验锁定 SHA256。即使运行时可 import，也必须有可信原始归档核对；缓存缺失须联网重新获取，无可信归档且断网则停止。保留缓存可支持健康环境离线重复运行，此包不是离线安装包。
3. 安装完成重启 Premiere，检查环境与短素材。多处 CEP 同 ID 副本仍需用户处理。

发行文件名为 `arknight-pr-setup-v0.2.0-windows-x64.zip`（完整在线安装入口）、`com.arknight.autoediting-v0.2.0.zip`（仅面板）与 `com.arknight.autoediting-v0.2.0.zxp`（签名面板）。

setup 不改系统 Python/PATH，不携带 FFmpeg；默认 OpenCV 分析不需要 FFmpeg。要使用 FFmpeg 解码或播放代理，请另行安装配置。仅面板 ZIP/ZXP 用户需自行配置 Python 与 backend。安装位置、备份恢复、许可和复测命令见[安装说明](../installation-options.md)。

- 新版完整分析→编辑→落地→保存关闭重开链路尚未逐项验收；源入出点语义、音频精度及 overwrite 兜底未完整验证，宿主结果仍可能为 partial。
- 0.2x 仍有过场假阳性，需人工复核；严格静止实验规则默认关闭，缺少独立标注集上的完整操作保护验收。

## 可复现检查

从仓库根目录运行，环境要求见[贡献指南](../../CONTRIBUTING.md)：

```bash
node tools/check.js
node tools/check-links.js
node tools/test-all.js
```

全测试包含后端、预览与安装检查；需要测试 Python 的 NumPy/OpenCV，代理测试需 FFmpeg/ffprobe。非 Windows 会跳过真实 Windows 安装，不能当作该项通过。真实素材和用户日志未纳入发行包；保留原始记录中的测量数值，不修改历史证据。
