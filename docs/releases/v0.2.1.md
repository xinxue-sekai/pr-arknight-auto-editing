# v0.2.1 · 2026-11-24

此版本为兼容性补丁，新增 Windows x64 离线 setup；在线安装、内置后端、视频预览与交互行为与 v0.2.0 相同。版本来源为 `cep-extension/CSXS/manifest.xml`，bundle 与 panel 均为 0.2.1；CEP schema 仍为 7.0，manifest 的 Host 范围与 `config.json` 格式未变。历史 v0.2.0 发布说明与验证记录保持原样。

## 新功能

- Windows x64 离线 setup：`arknight-pr-setup-offline-v0.2.1-windows-x64.zip` 在在线 setup 相同内容外附带与 `setup.bat` 同级的 `runtime-deps/`，内含 `runtime-lock.json` 锁定的 CPython 3.13.2、NumPy 2.2.3 与 opencv-python-headless 4.11.0.86 原始归档。
- 离线安装使用 `setup.ps1 -Offline`，安装期间禁止网络请求，只使用包内归档或已校验的本地缓存；缺件、损坏或 SHA256 不符时报告具体文件名后停止，不回退在线下载。安装位置、健康检查、升级与回滚行为与在线 setup 相同。
- Release 自本版本起要求离线 setup 附件，并在创建 Release 前校验 `runtime-deps/` 的文件名与锁定 SHA256。

## 修复与文档

- 修正安装说明手工缓存章节的页内锚点，指向 `#v020-下载超时的手工缓存办法`。
- 安装说明明确区分当前 v0.2.1 的在线/离线 setup 与历史 v0.2.0 只有在线包的状态；v0.2.0 的手工缓存办法保留，供仍安装该历史版本的用户使用。
- 版本元数据同步为 0.2.1；v0.2.0 的发行说明、测量数值与真机记录不重写。

## 安装与升级

1. 在线安装：下载 `arknight-pr-setup-v0.2.1-windows-x64.zip`，完整解压到新目录，关闭 Premiere，双击 `setup.bat`。首次安装需访问 python.org 与 files.pythonhosted.org。
2. 离线安装：下载 `arknight-pr-setup-offline-v0.2.1-windows-x64.zip`，完整解压到新目录，关闭 Premiere，双击 `setup.bat`。必须保留与 `setup.bat` 同级的整个 `runtime-deps/`；不要只复制该目录到在线包旁边，也不要替换其中文件。
3. 两种 setup 都按 `runtime-lock.json` 核对归档 SHA256。健康组件复用；面板与后端按内容更新，失败回滚。安装完成重启 Premiere，检查环境与短素材。多处 CEP 同 ID 副本仍需用户处理。

发行文件名为 `arknight-pr-setup-v0.2.1-windows-x64.zip`（在线安装入口）、`arknight-pr-setup-offline-v0.2.1-windows-x64.zip`（离线安装入口）、`com.arknight.autoediting-v0.2.1.zip`（仅面板）与 `com.arknight.autoediting-v0.2.1.zxp`（签名面板）。

setup 不改系统 Python/PATH，不携带 FFmpeg；默认 OpenCV 分析不需要 FFmpeg。要使用 FFmpeg 解码或播放代理，请另行安装配置。仅面板 ZIP/ZXP 用户需自行配置 Python 与 backend。安装位置、备份恢复、许可、历史 v0.2.0 手工缓存和复测命令见[安装说明](../installation-options.md)。

## 已验证与已知限制

本版本沿用 v0.2.0 的自动测试、隔离安装与真机验证结论，未新增全片识别准确率、干净 Windows 或完整链路真机验收。离线包的端到端部署体验仍待验收。验证范围、性能证据与限制见[验证状态与已知限制](../verification-status.md)。

- 新版完整分析→编辑→落地→保存关闭重开链路尚未逐项验收；源入出点语义、音频精度及 overwrite 兜底未完整验证，宿主结果仍可能为 partial。
- 0.2x 仍有过场假阳性，需人工复核；严格静止实验规则默认关闭，缺少独立标注集上的完整操作保护验收。
- 浏览器剪后播放是跳切试听，不保证帧精确剪接或长期音画同步。
- 干净 Windows 无开发工具环境、其他 Premiere 版本及离线包部署体验未完成验收；强杀/断电、回滚期间二次文件占用等不属于已有全面实测范围。
- 自动测试与历史素材结果不替代本版本全部真机验收，也不提供准确率保证。

## 可复现检查

从仓库根目录运行，环境要求见[贡献指南](../../CONTRIBUTING.md)：

```bash
node tools/check.js
node tools/check-links.js
node tools/test-all.js
```

全测试包含后端、预览与安装检查；需要测试 Python 的 NumPy/OpenCV，代理测试需 FFmpeg/ffprobe。非 Windows 会跳过真实 Windows 安装，不能当作该项通过。Release 另运行 `node tools/package.js --offline` 与 `node tools/verify-package.js --offline` 核对离线包及 `runtime-deps/` 的锁定 SHA256。真实素材和用户日志未纳入发行包；保留原始记录中的测量数值，不修改历史证据。
